# Trova-il-Tuo-Amico
Durante il tirocinio scolastico, ho realizzato insieme a una compagna un programma con un questionario per aiutare l'utente a scegliere l'animale più adatto alle proprie esigenze. In base alle risposte e al punteggio ottenuto, l'intelligenza artificiale fornisce informazioni e suggerimenti specifici sull'animale selezionato.

Per farlo funzionare serve
Python 3, libreria requests, connessione Internet, chiave API personale di Groq e assicurarsi che il modello AI sia disponibile.

Avvio: installare requests con pip install requests, inserire la propria chiave API nel codice (riga 5), assicurarsi che il modello sia valido in caso di errore (riga 124) ed eseguire il file Python.
